# 🌐 Personal Website — Eduardo

Personal website built with **Vite + React**, designed as a minimalist landing page to showcase my professional profile, skills, and selected projects.  
The goal is to have a simple, fast, and clear online CV.

## ✨ Features
- Minimalist design inspired by modern developer portfolios
- Sections: Hero, About, Skills, Projects, and Contact
- Single Page Application (SPA) using React
- Contact form ready for integration with EmailJS, Resend, or a custom backend
- Deployed on GitHub Pages

## 🛠️ Tech Stack
- React
- Vite
- Minimal CSS styling
- GitHub Pages (deployment)
